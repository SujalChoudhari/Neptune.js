# Debug project runtime smoke

From the repository root, run `npm test`. The smoke test boots this project's actual `main.js`, loads the Town's scene and referenced tilemap through `SceneLoader`, verifies the player and tile entities, confirms the safe square contains no hostile slimes, and fails on any `console.error` during startup. It also walks the player through the purple stairs into the dungeon, verifies three slime enemies navigate to and attack the player, and returns to town while checking the player is preserved and the destination reused. The test uses a local filesystem-backed fetch adapter and the repository's browser mocks; it does not replace the sample scene or loader with fixtures.

To try the sample interactively in a browser, start a static server from the repository root (for example, `python3 -m http.server 8000`) and open `http://localhost:8000/debug_project/`. Press Play Game to start the canvas runtime; use the arrow keys to move the player. Press E near the Town Guide to read dialogue, start the Slime Trouble quest, and receive a Training Blade. The quest advances as dungeon slimes are defeated. Walk to the purple stairs and press E to enter the dungeon; press U to equip the blade and increase melee damage. Three slimes navigate the dungeon grid and attack when close. Press J for a melee slash or K for a ranged bolt, both aimed in the player's last horizontal movement direction. Defeating a slime drops slime gel and grants XP. Press E at the dungeon stairs to return to town.
